# MSCC - Site

This is an [Astro](https://astro.build) site built with [Bun](https://bun.com) and [Typescript](https://typescriptlang.org), and deployed with [Netlify](https://netlify.com).

## Local Development

1. Clone this repo.
2. Install Bun.
3. Run `bun install` in the root folder.
4. Start the dev server with `bun run dev`.
5. Navigate to localhost:4321 and observe changes updating in real-time.
