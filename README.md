# MSCC - Site

This is an [Astro](https://astro.build) site built with [Bun](https://bun.com) and [Typescript](https://typescriptlang.org), and deployed with [Netlify](https://netlify.com).

## Local Development

1. Clone this repo.
2. Install Bun.
3. Run `bun install` in the root folder.
4. Start the dev server with `bun run dev`.
5. Navigate to localhost:4321 and observe changes updating in real-time.

## Making a change

This repo is hosts on Netlify, which automatically builds and deploys any new commits to main.
Therefore, all changes are required to have a new branch and PR:
1. Check out a branch using the convention `<lastname>/<featurename>` (for example, `smith/some-random-feature`).
2. Commit and push your changes to this branch.
3. Ensure everything works as expected locally.
4. Open a PR to merge your branch into main.
> NOTE: If a feature branch has multiple commits (for any reason, like addressing comments), all commits should be squashed into one before merging.
